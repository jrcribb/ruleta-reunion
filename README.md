# Ruleta Reunión

Aplicación web autónoma para organizar turnos de participación en reuniones mediante una ruleta visual.

## Características

- Sorteo aleatorio sin repetir participantes durante una ronda.
- Temporizador general de la reunión y cronómetro por participante.
- Tiempos individuales configurables.
- Indicadores visuales según el tiempo consumido.
- Pausa, reanudación, finalización y reinicio de rondas.
- Ordenamiento de participantes por tiempo hablado.
- Selección manual mediante doble clic.
- Persistencia local de la configuración y del estado de la reunión.
- Diseño adaptable y funcionamiento sin conexión.

## Uso

1. Descarga o clona este repositorio.
2. Abre `ruleta-reunion-v10.html` en un navegador moderno.
3. En **Configurar**, define el título, la duración de la reunión y los participantes.
4. Pulsa **Girar** para iniciar el sorteo.

No requiere instalación, servidor web ni dependencias externas.

## Versiones

La versión actual es `ruleta-reunion-v10.html`. Las versiones anteriores se conservan como referencia histórica.

## Almacenamiento

Los participantes, tiempos y estado de la reunión se guardan en el almacenamiento local del navegador. Estos datos no se envían a servicios externos.
